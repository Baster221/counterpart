# Reviewer guide

Read `_matrix`, the validator inside `clear`, and `_maximum_matching` first. The model decides the semantic graph; deterministic code owns capacity and allocation. Participant consent is a separate deterministic state transition.

| Question | Enforced answer |
|---|---|
| Does confidence affect matching without exact validator agreement? | Confidence is compared exactly for every cell; only high-confidence bilateral YES creates an edge. |
| Can the leader exclude plausible pairs? | The parser requires exactly demand_count×supply_count unique cells, and every validator independently judges the same full set. |
| Can a quoted keyword add an unverified category or edge? | There are no extracted categories or quote-only checks. Fulfillment and admissibility require substantive independent classification of complete text. |
| Does the model choose a favorite winner? | No. The optimizer enumerates bounded injective assignments, maximizes cardinality and uses a fixed tie-break. |
| Can the coordinator accept for participants? | No. Only the two matched addresses can confirm their snapshot; both are required. |
| Does this certify real human/team identity? | No. Addresses are consent principals; specifications are offers. No identity-dependent benefit, verified skill or global availability claim exists. |
| Is the supplied deployment corrected and identical to GitHub? | Read-only source equality and receipt verification are provided; CI checks the deployment manifest against local source. |

## Distinct architecture

This contract has no multi-source claim registry, publisher/challenger adjudication lifecycle, release-promotion gate, privacy certificate or retro-funding ranking. A full compatibility matrix followed by one-to-one optimal allocation and bilateral acceptance is its on-chain behavior. It also differs from ScopeLock: no delegated authority, reserved unit budgets, nonce permits or consuming adapter exist here.

## Why the bounds matter

Four slots per side permit all-pairs semantic evaluation without pruning and complete deterministic optimization without heuristic shortcuts. The independent graph-reference test covers all 512 possible 3×3 graphs. Larger deployments would need a different batching and optimizer design, rather than silently raising this bound and assuming constant cost.

## Reuse

Technical writing cooperatives, review exchanges and volunteer task batches can post exact requirements and restrictions. The result is a maximum set of compatible consent-bound pairs, subject to explicit uncertainty and finality boundaries. It is not a marketplace payment system or evidence that work was delivered.
